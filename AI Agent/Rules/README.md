# Rules — politiques IA-TB Game Master

Ordre d'application : sécurité de la plateforme et du fournisseur > permissions effectives > Rules/Non-Authorized > Rules/Authorized > instructions de tâches/Skills.

- Authorized/ : actions permises **uniquement si l'accès technique requis existe** et si les contrôles de sécurité de l'opération ont réussi.
- Non-Authorized/ : actions interdites même si une interface les rendrait techniquement possibles.

Une permission documentaire n'équivaut pas à un accès système. Ne pas considérer une opération comme réussie sans réponse de l'outil et, pour un déploiement, sans contrôle de santé côté VPS.
