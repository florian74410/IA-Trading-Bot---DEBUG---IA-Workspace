# Skills — IA-TB Game Master

Chaque compétence est séparée et décrit un flux de travail reproductible, les outils réellement disponibles, les prérequis, les preuves à conserver et les interdictions.

- SSH/SKILL.md — accès SSH restreint et vérification de connexion.

Les Skills sont des **consignes exécutables par un assistant lorsqu'il dispose des outils correspondants** ; les fichiers seuls ne créent pas de sessions SSH ni de privilèges. Avant chaque tâche, respecter Rules/.
