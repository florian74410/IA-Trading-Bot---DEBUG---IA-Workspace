# Episodic Memory

Interventions, sessions de travail, incidents et résolutions, sous forme de synthèses
explicites. Dans v0.2, le journal SQLite **General** reste la source append-only
effective. Classer les épisodes par `kind`, `reference` et identifiants de commits.
Aucune mémoire n'est injectée dans le contexte sans filtrage de provenance.
